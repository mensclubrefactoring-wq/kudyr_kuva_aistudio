# Kudyr Kuva: The Hidden One

A 2D stealth game based on Mari mythology.

## Story
You play as **Kudyr Kuva**, a mystical creature (similar to a kikimora) who lives alongside humans but must remain unseen. Your goal is to collect forgotten items from the human world to build your own magical home.

## Gameplay
- **Objective**: Collect 30 items and deliver them to your hidden portal.
- **Inventory**: You can carry a maximum of 6 items at a time.
- **Stealth**: Avoid the vision cones of humans. If they see you, the game is over.
- **Levels**:
  1. **The Yard**: Open area with patrolling humans.
  2. **The Cellar**: Narrow passages and limited visibility.
  3. **The Barn**: Unpredictable movement and many obstacles.

## Controls
- **WASD** or **Arrow Keys**: Move Kudyr Kuva.
- **Mouse**: Navigate menus.

## Technical Details
- Built with **React** and **Canvas API**.
- Styled with **Tailwind CSS**.
- Animations powered by **Framer Motion**.
- Icons by **Lucide React**.

## How to Run
1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Open `http://localhost:3000` in your browser.

## Deployment
This project is ready for deployment as a static site (e.g., GitHub Pages).
Run `npm run build` and deploy the contents of the `dist` folder.
